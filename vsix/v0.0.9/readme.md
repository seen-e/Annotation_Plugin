# Image Annotator v0.0.9

Package:

```text
image-annotator-0.0.9.vsix
```

Adds display-only image enhancement controls.

Changes from v0.0.8:
- Added a right-side `View` section.
- Added `Brightness` slider.
- Added `Contrast` slider.
- Added `Reset View` button.

Notes:
- Brightness and contrast changes only affect the webview display.
- The source image file is not modified.
- Bbox coordinates are still saved in original image pixel coordinates.
