# Image Annotator v0.0.4

Package:

```text
image-annotator-0.0.4.vsix
```

Adds symmetric right-side image navigation.

Changes from v0.0.3:
- Added a right-side `<- Previous` button.
- Right-side previous and next buttons both save the current image before switching.
- Button disabled states now follow the current image index.
- Keyboard navigation remains `A` / `ArrowLeft` and `D` / `ArrowRight`.
