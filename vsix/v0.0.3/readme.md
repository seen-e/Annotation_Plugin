# Image Annotator v0.0.3

Package:

```text
image-annotator-0.0.3.vsix
```

Adds a faster right-side next-image workflow.

Changes from v0.0.2:
- Added a right-side `Next ->` button above the `Labels` section.
- Clicking `Next ->` saves the current annotation state and opens the next image.
- `D` and `ArrowRight` keep the same save-and-next behavior.
- The right-side next button is disabled on the last image.
