# Image Annotator v0.0.10

Package:

```text
image-annotator-0.0.10.vsix
```

Updates the default label set.

Changes from v0.0.9:
- Default labels are now `left` and `right`.
- Default labels no longer include hotkeys.

Notes:
- This only applies when the dataset root does not contain `annotation.yaml`.
- Existing `annotation.yaml` files still take priority.
